
# Hotel Management System - Complete Blueprint for V0.dev

## Overview
Create a comprehensive hotel management system with a modern, professional UI using Next.js. The application should have a responsive design that works well on desktop and mobile devices. The system needs to manage bookings, rooms, expenses, cleaning status, users, owners, and provide reporting capabilities with audit logs.

## Color Palette
- Primary Blue: `#3B82F6` (tailwind blue-500) - Use for primary buttons, active states, and links
- Primary Blue Hover: `#2563EB` (tailwind blue-600) - Hover state for primary buttons
- Primary Blue Light: `#DBEAFE` (tailwind blue-100) - Background for highlighted items
- Secondary Gray: `#F3F4F6` (tailwind gray-100) - For backgrounds, cards, and secondary elements
- Secondary Gray Dark: `#9CA3AF` (tailwind gray-400) - For borders and dividers
- Success Green: `#10B981` (tailwind green-500) - For success states, confirmations
- Success Green Light: `#D1FAE5` (tailwind green-100) - Background for success states
- Warning Amber: `#F59E0B` (tailwind amber-500) - For warning states, pending actions
- Warning Amber Light: `#FEF3C7` (tailwind amber-100) - Background for warning states
- Error Red: `#EF4444` (tailwind red-500) - For error states, critical actions
- Error Red Light: `#FEE2E2` (tailwind red-100) - Background for error states
- Info Blue: `#3B82F6` (tailwind blue-500) - For informational states
- Info Blue Light: `#DBEAFE` (tailwind blue-100) - Background for informational states
- White: `#FFFFFF` - Background for cards, modals, content areas
- Off-White: `#F9FAFB` (tailwind gray-50) - Page backgrounds
- Light Gray: `#E5E7EB` (tailwind gray-200) - Borders, dividers, inactive states
- Medium Gray: `#6B7280` (tailwind gray-500) - Secondary text, icons
- Dark Gray: `#374151` (tailwind gray-700) - Primary text
- Black: `#111827` (tailwind gray-900) - Headings, important text

## Typography
- Primary Font: 'Inter', sans-serif
- Heading 1: 30px (1.875rem) - Page titles
- Heading 2: 24px (1.5rem) - Section titles
- Heading 3: 20px (1.25rem) - Card titles, modal headers
- Body Large: 16px (1rem) - Primary text
- Body Regular: 14px (0.875rem) - Secondary text, form labels
- Body Small: 12px (0.75rem) - Captions, helper text
- Micro: 10px (0.625rem) - Badges, tags
- Font Weights: Regular (400), Medium (500), Semibold (600), Bold (700)
- Line Heights: Tight (1.25) for headings, Regular (1.5) for body text, Loose (1.75) for paragraphs

## Global Layout
- Create a responsive layout with:
  - Header (h-16, fixed top, white background, border-b, px-6)
  - Sidebar (w-64 on desktop, collapsible on mobile)
  - Content Area (p-6, bg-background)
- Sidebar should collapse on smaller screens and expand via hamburger menu
- Maximum content width of 1600px with mx-auto
- Subtle fade-in animations for content when pages load
